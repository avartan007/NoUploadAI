Small file tools.
Zero uploads.

Three runnable, single-page utilities that never send a byte anywhere. They ship as plain HTML, CSS and JavaScript inside this showcase repository — no build step, no backend, no analytics. Open one, drop a file, and watch the work happen in your browser.

runnable demo

01 / Compress

Image compressor

Resize and re-encode JPEG, PNG or WebP on a canvas. Tune quality and max width, compare byte sizes, download the result.

Open tool →
runnable demo

02 / Scrub

Metadata scrubber

Read real EXIF fields — camera, timestamp, GPS — then re-encode the pixels so none of it travels with the file you share.

Open tool →
runnable demo

03 / Optimize

SVG optimizer

Strip comments, editor metadata and dead attributes; round coordinates and collapse whitespace while keeping a live preview.

Open tool →

These demos illustrate the NoUpload design philosophy alongside the main local-RAG workspace. They are not bundled into the NoUploadAI application build; the source for the RAG product lives in the private NoUploadAI-SRC repository.
